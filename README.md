The word you'd delete from the dictionary: **colonel** — spelled like a military rank, pronounced like a popcorn kernel. Erase it and every colonel is honestly a kernel. A small Python program that scores a shortlist of candidate words against the judge's brief (a real word first, then funny at first sight, then the humour coming from the word itself, then fresh, then exact) and writes the winning word to `/output/entry.txt`. The entry is validated before writing: one word, 1–77 characters, no leading or trailing whitespace, no newline.

## Run it

```sh
python3 main.py
```
